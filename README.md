# YANG11 实验室进度协作台

面向实验室教师和学生的甘特图进度管理系统。前端保留原项目的任务甘特图、进度记录、评价、成员管理、档案、历史和导入导出功能；后端新增统一登录、SQLite 持久化和角色权限控制。

## 技术栈

- 前端：React 19、TypeScript、Vite、Tailwind CSS、shadcn/ui
- 后端：FastAPI、SQLite、Pydantic
- 认证：bcrypt 密码哈希、服务端会话、HttpOnly Cookie

登录时，管理员输入管理员账号，学生输入学号。原型中的两名示例学生会保留为临时账号 `p2`、`p3`，但不会保留旧弱密码；管理员登录后需要在“账户管理”中为其填写真实学号并设置新密码。

所有新密码至少 8 位，并且必须同时包含大写字母、小写字母和数字。管理员可以新增学生或管理员账户、修改账号/学号和姓名、重置密码、停用、启用或删除账户。当前登录账户不能停用或删除。

生产部署前可通过环境变量 `GANTT_ADMIN_PASSWORD` 指定首次数据库迁移时的管理员密码；完成迁移后，服务重启不会覆盖管理员后来设置的密码。

## 本地开发

前端：

```bash
npm install
npm run dev
```

后端：

```bash
python -m venv .venv
.venv/bin/pip install -r backend/requirements.txt
.venv/bin/uvicorn backend.app:app --reload --port 8000
```

Windows PowerShell 使用 `.venv\Scripts\pip.exe` 和 `.venv\Scripts\uvicorn.exe`。Vite 开发服务器运行在 `http://localhost:3000`，并自动把 `/api` 转发到 `http://localhost:8000`。

## 生产运行

```bash
npm run build
python -m uvicorn backend.app:app --host 0.0.0.0 --port 8000
```

FastAPI 会直接托管 `dist` 中的前端，访问 `http://localhost:8000` 即可。SQLite 数据默认保存在 `data/gantt.db`，可通过 `GANTT_DATA_DIR` 指定其他目录；HTTPS 部署时设置 `GANTT_SECURE_COOKIE=1`。

## 进展记录附件

学生和教师都可以在任务面板「进展与问题」中提交进展记录或回复时附带附件（格式不限），双方可互相下载。

- 单个附件默认上限 50MB，可用环境变量 `GANTT_MAX_ATTACHMENT_MB` 调整，超限返回 413。
- 附件本体保存在 `data/attachments/`（目录名即随机附件 ID），元数据随任务记录存入 SQLite；迁移服务器时需要连同数据目录一起复制。
- 下载走 `GET /api/attachments/{id}`，按所属任务的可见性鉴权：学生私有任务的附件对教师同样不可下载。
- 同步码/JSON 备份只携带附件引用不携带文件本体，跨服务器导入后原附件链接会失效。
- 上传后未随记录保存、或记录被删除产生的孤儿文件暂不自动清理。

## AI 助手（服务器 Claude Code）

登录后任意页面右下角有 AI 悬浮球，所有角色可用：自由对话（可上传文本/Excel 附件）、自然语言快速建任务、上传学生花名册批量创建账号（仅教师/管理员）。

- AI 通道为服务器上的 `claude` CLI 子进程（无外部 API Key）；管理员在「系统管理 → AI 设置」开启，可指定模型；CLI 以空工具白名单运行，纯文本推理，无法操作服务器。
- 每个用户可多开对话，聊天记录持久化在 SQLite；同一对话通过 Claude Code 的 session 自动续上下文，上下文将满时由其内建 auto-compact 自动压缩；session 失效会自动带最近历史降级重发。
- 回复为 SSE 流式输出，事件带序号，浏览器断线后按序号重连重放不丢内容；抽屉关闭期间完成的回复会在悬浮球上显示红点。
- 同一对话同时只允许一轮回复（409），全站并发上限默认 4（环境变量 `GANTT_AI_CONCURRENCY`），单轮超时默认 180 秒（`GANTT_AI_TIMEOUT`）。
- AI 会话工作目录保存在 `data/ai-sessions/`，删除对话会一并清理；批量建号的初始密码由管理员提供，未提供时 AI 会在对话中主动询问。

## 权限边界

- 管理员可查看并管理全部账户、任务、评价和档案管理字段。
- 工作区按归属隔离：教师/管理员只能看到自己创建的学生、其任务与档案；新建教师登录即为空白工作台，与其他教师（含管理员）互相不可见。历史无归属的学生默认归管理员。
- 学生从后端只能取得自己的任务和自己的公开档案数据；学生端不提供档案界面。
- 学生保存时，后端只合并该学生名下的任务与公开档案，不接受人员表、其他成员任务或教师专用档案字段的修改。
- 学生可将自建任务设为「仅自己可见」：教师与管理员的读取会被服务端过滤，教师端保存也不会覆盖删除这些私有任务；私有任务的附件对教师同样不可下载。
- 停用账户可登录进入离线模式（只读，保存被拒绝、AI 不可用），删除后级联清除会话彻底锁定；所有角色可自助修改密码（右上角用户菜单）。
- 密码不再进入前端业务数据、备份文件或同步码。
